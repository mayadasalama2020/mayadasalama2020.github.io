Clinical Pharmacy Performance Analysis

Designed the relational schema in SSMS to consolidate pharmacy logs from several hospitals, then used aggregation queries (GROUP BY, ORDER BY, SUM, WHERE) to compare intervention volumes.

Result: a ranking of Mansoura General, Talkha Central and Mit Ghamr hospitals by interventions.

Add sql-output-1.png
schema_definition.sql
CREATE TABLE C_pharmacy_performance (
  record_id INT PRIMARY KEY,
  hospital_name VARCHAR(100),
  interventions_count INT,
  month VARCHAR(20)
);
aggregation_query.sql
SELECT hospital_name,
  SUM(interventions_count) AS total_interventions
FROM C_pharmacy_performance
GROUP BY hospital_name
ORDER BY total_interventions DESC;
